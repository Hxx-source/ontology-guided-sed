00 / ABSTRACT

Why this work?

Query-based sound event detection (SED) uses class queries to condition event recognition and temporal localization. Recent advanced frameworks, represented by the Detect Any Sound Model (DASM), achieve state-of-the-art performance on benchmarks like AudioSet by integrating class queries, cross-modal decoding, and frame-level mask prediction. However, in the practical audio-query setting, DASM faces two key challenges when detecting fine-grained and long-tailed sound events: first, query representations for rare subclasses suffer from data scarcity, background co-occurrence, and prototype noise; second, its reliance on a single, global median-filtering window ignores the substantial temporal scale heterogeneity across different event classes. To address these limitations, we propose an enhanced audio-query framework for target classes with training data. Specifically, Ontology-Guided Consistency Learning (OCL) regularizes refined queries via selected child-parent relations, complemented by Class-Wise Adaptive Weighting (CAW) that dynamically scales this regularization based on child-to-parent duration ratios. Furthermore, Class-Adaptive Median Filtering (CAMF) estimates class-specific smoothing windows from training durations using knee-based subset selection and a trimean estimator. Extensive experiments on AudioSet demonstrate that our method increases the overall Polyphonic Sound Detection Score (PSDS) from 49.73% to 51.26% and rare-class PSDS from 37.50% to 40.68%. These results confirm that our approach effectively strengthens long-tailed query representations while mitigating temporal scale mismatches in post-processing.

03 / THE METHOD

Knowledge transfer meets time-scale adaptation.

Two complementary interventions address the two limitations described in the paper.

01 / QUERY REPRESENTATION

OCL

Ontology-Guided Consistency Learning regularizes refined queries through selected child–parent relations, transferring reliable hierarchical knowledge to data-scarce subclasses.

02 / RELATION STRENGTH

CAW

Class-Wise Adaptive Weighting scales the consistency term by child-to-parent duration ratios, so not every ontology relation contributes equally.

03 / POST-PROCESSING

CAMF

Class-Adaptive Median Filtering estimates a window for each event class from training durations using knee-based subset selection and a trimean estimator.
