01 / EVIDENCE

每一步带来了什么

AudioSet-Strong 验证集，PSDS1 设置；仅 381 个类别有有效逐类标注。百分数来自论文表 I，不是本页精选音频的得分。

02 / METHOD

两条互补的改进路径

01 · OCL

父类作为语义锚点

从 AudioSet 本体中筛选可靠父子关系，只在训练时用层级一致性约束查询表示。父类与子类可以同时检出，不是互斥分类。

02 · CAW

逐关系调整迁移强度

依据子/父训练时长比、父类支持量及查询相似度，为每条关系设置不同权重；一个子类有多个父类时分别计算。

03 · CAMF

逐类别选择时间尺度

从训练事件时长分布估计每类中值滤波窗口：短促事件保留瞬态，持续事件抑制碎片化。无需新增推理参数。
